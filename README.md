# Exploratory Data Analysis (EDA) on Titanic Dataset

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to discover patterns, trends, and relationships that influenced passenger survival.

## Features

- Load and inspect dataset
- Handle missing values
- Generate statistical summaries
- Visualize data using charts
- Analyze feature correlations
- Identify key insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Output

- Survival Count
- Gender Distribution
- Passenger Class Distribution
- Age Distribution
- Fare Distribution
- Correlation Heatmap

## Run

```bash
pip install -r requirements.txt
python eda_analysis.py
```
